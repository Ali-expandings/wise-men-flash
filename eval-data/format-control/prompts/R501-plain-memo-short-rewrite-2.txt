**Connection pooling.** This is the one real landmine, but it's a solved problem, not a reason to avoid RLS. The failure mode is using session-level `SET` with a pooler in transaction mode (PgBouncer), where a connection can get reused across different logical requests without resetting state. The fix is to always scope the tenant setting to the transaction with `SET LOCAL` (or `set_config(name, value, true)` — the `true` means local), issued inside the same transaction as the query.
